Educação Digital

Aprendendo a criar páginas para a web

Sobre a disciplina

Nesta disciplina vamos aprender a construir páginas para a internet usando HTML e CSS. O HTML é a estrutura da página, e o CSS é o que deixa a página bonita.

O que vamos aprender

  • Criar a estrutura de uma página com HTML
  • Adicionar títulos, textos e imagens
  • Mudar cores e fontes com CSS
  • Publicar a página na internet
